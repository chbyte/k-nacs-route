경로 위 충전 휴게소

      출발지와 도착지를 넣고 "경로에서 찾기"를 누르세요.
      설정 (주소 검색 · 충전기 데이터)
      상세주소 검색: 카카오 개발자 사이트(developers.kakao.com)에서 앱을 만들고 JavaScript 키를 넣으면 도로명·지번 주소와 상호명으로 정확하게 찾습니다. 앱 설정의 플랫폼 → Web에 이 페이지 주소(도메인)를 등록해야 해요. 키가 없으면 무료 지도 검색(정확도 낮음)을 씁니다.
      충전기 정보는 공공데이터포털의 한국환경공단_전기자동차 충전소 정보 API에서 받아옵니다. 공공데이터포털에서 활용신청하면 개발계정은 바로 승인되고, 받은 일반 인증키를 아래에 넣으면 됩니다. 이 기기 브라우저에만 저장돼요.
      API 호출이 브라우저에서 막히면, 같은 데이터를 파일(CSV/JSON)로 받아 여기서 불러올 수도 있습니다.
